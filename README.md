# Credit Risk Decision System

An AI-powered credit risk decision platform that combines **Machine Learning, Explainability, Web Scraping, NLP, and LLMs** to automate smarter loan approval decisions.

This project is currently in the **architecture and development setup phase**.

The detailed project architecture is available in `projectplan.png`.

---

## Goal

Build a production-ready credit intelligence platform that makes lending decisions more **accurate, explainable, and customer-friendly**.
